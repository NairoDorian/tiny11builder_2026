Place optional browser installer scripts here.
Each .ps1 or .cmd file is a self-contained browser installer.

Example browsers:
  - firefox.ps1          - Mozilla Firefox (latest, silent install)
  - chrome.ps1           - Google Chrome (latest, silent install)
  - librewolf.ps1        - LibreWolf (privacy-focused Firefox fork)
  - brave.ps1            - Brave Browser

These are NOT executed automatically during build. They are provided
as optional post-install scripts that you can run manually after
the ISO is installed on real hardware.

Inspired by the DFwindows11_builder fork's Browsers folder structure.
